So funktioniert's:
1. NetworkMonitor.ps1 auf dem Windows-Client starten
2. Ping-Ziele, iperf3-Server und Testdauer in der GUI konfigurieren
3. Monitoring starten - Daten werden in SQLite-Datenbank gespeichert
4. Hier im Dashboard die .db-Datei laden
5. Sessions einzeln oder alle zusammen auswerten

Voraussetzung:
- PowerShell-Modul PSSQLite (wird beim ersten Start automatisch installiert)
- iperf3.exe auf dem Client (Download)
- iperf3-Server auf dem Ziel: iperf3 -s

Schwellwerte:
- Jitter > 30ms: Verbindungsabbrueche wahrscheinlich
- Paketverlust > 1%: Bildschirmfreezes, Eingabeverzoegerungen
- TCP-Retransmits hoch: Netzwerkueberlastung / Duplex-Mismatch
- Ping-Ausfaelle: Routing-Problem oder Gateway-Ueberlastung

Network Health Score:
- Berechnet aus Jitter, Paketverlust, Retransmits und Ping-Verfuegbarkeit
- GUT (80-100): Netzwerk in gutem Zustand
- EINGESCHRAENKT (50-79): Probleme moeglich, Ursache pruefen
- KRITISCH (0-49): Netzwerk stark beeintraechtigt

Datenbank-Schema:
- Tabelle sessions: Metadaten jeder Messung (Dauer, Ziele, Intervalle)
- Tabelle ping: Alle Ping-Ergebnisse mit Latenz und TTL
- Tabelle iperf: TCP/UDP iperf3-Ergebnisse je Richtung (Upload/Download: Bandbreite, Jitter, Loss, Retransmits)

CSV-Export:
- Ping-CSV und iperf-CSV Buttons exportieren die aktuelle Session-Auswahl
- Daten werden in die Zwischenablage kopiert oder als Textfeld angezeigt
